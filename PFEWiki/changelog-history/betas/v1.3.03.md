### Added [Flash Freezer](../../blocks/automation/flash-freezer.md)

* This new [automation block](../../blocks/automation/) when powered with [Redstone](https://minecraft.wiki/w/Redstone); will convert [Water](https://minecraft.wiki/w/Water) into [Ice](https://minecraft.wiki/w/Ice)

### [Trapdoors](../../blocks/trapdoors/) can now be opened & closed via a [Redstone signal](https://minecraft.wiki/w/Redstone_mechanics#Redstone_signal)

### Most [automation blocks](../../blocks/automation/) will now only activate via a [Redstone signal](https://minecraft.wiki/w/Redstone_mechanics#Redstone_signal)

{% hint style="info" %}
This means that these blocks will no longer "loop" its action while it is powered, rather now it will only activate once when it is powered.



Additionally this also makes it so there is no longer a delay between activating the block & it actually triggering.



Though this does break most if not all of the existing farms; this should hopefully give people more precise control over the timing on their future machines.



For now this change affects:

* [Cobblestone Generator](../../blocks/automation/cobblestone-generator.md)
* [Cobbler](../../blocks/automation/cobbler.md)
* [Block Breaker](../../blocks/automation/block-breaker.md)
* [Duster](../../blocks/automation/duster.md)
* [Dirter](../../blocks/automation/dirter.md)
* [Flash Freezer](../../blocks/automation/flash-freezer.md)
* [Magnet (Block)](../../blocks/automation/magnet-block.md)
{% endhint %}
